# Data and Code for "Brood and offspring size variation in two similarly sized spiders and the role of maternal provisioning and predation risk"

# Overview
This repository contains the raw data and R scripts used in the manuscript

> **Cline, Z. A., & Harvey, J. A. (2025).** Brood and offspring size variation in two similarly sized spiders reveal differing altricial and precocial modes of development. *Journal of Evolutionary Biology* (submitted). 

# Data Availability
The data and analysis scripts supporting this study are archived in Zenodo and publicly available at:
🔗 [https://doi.org/10.5281/zenodo.14861231](https://doi.org/10.5281/zenodo.14861231)

The original GitHub repository can be accessed at:
🔗 [https://github.com/Zach-Cline/Sf-Zs-Brood-and-offspring-size-variation-.git](https://github.com/Zach-Cline/Sf-Zs-Brood-and-offspring-size-variation-.git)
